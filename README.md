# ShopPilot — 电商售后智能客服 Agent（Python）

一个完整的电商售后客服 Agent:能查订单物流、答政策 FAQ、走退款 / 价保子流程,
带工具审计、置信度闸、数据飞轮与主题分类器。



## 能力一览

- **RAG 全链路**:向量 + Milvus 原生 BM25 混合召回 → RRF 融合 → 重排精排;Query 改写与子句拆分;
  三层切块(标题/分隔符/表格)。嵌入与重排模型可通过环境变量切换(示例配置:阿里云百炼 `text-embedding-v4` + `qwen3-rerank`)。
- **LangGraph 工作流**:12 节点图 —— 指代消解 → 十类意图分类 → 六出口分流;
  退款 / 价保子流程走 interrupt/resume(前端订单选择器、确认卡);
  生成前四信号置信度闸:不达标转人工兜底而不是硬答。
- **工具系统 + MCP**:内置 5 工具 + 2 台自建 MCP Server(物流 / 售后,独立进程);
  统一执行引擎:schema 校验 → 写操作权限位 → 只读重试 → 审计落表;写操作必须走用户确认卡。
- **语义缓存(二开)**:高频 FAQ 问题就近命中(嵌入余弦),命中即跳过检索与生成;带 TTL 与容量淘汰。
- **价保子流程(二开)**:第十类意图「价保」→ 确定性取单 → 价保政策检索 → Agent 判定 →
  `apply_price_protection`(MCP 写操作,确认卡 + 审计闭环)。
- **数据飞轮与可观测**:低置信问题落池 → 人工审核 → 回写知识库;Langfuse 自部署(可选);按意图成本账。
- **主题分类器**:chinese-roberta-wwm-ext 17 类多标签微调 → 阈值扫描 → ONNX 导出 → 轻量推理服务。
- **多上游适配(二开)**:重排支持 jina / aliyun / dashscope 三种接口形状;嵌入分片;百炼思考链开关。

## 快速开始

```bash
cp .env.example .env      # 上游二选一:硅基流动 / 阿里云百炼(两套示例都在文件里)
uv sync                   # Python 3.12(uv 自动管理)
docker compose up -d      # MySQL + Milvus(国内网络建议先配镜像加速)
make seed                 # 灌业务测试数据
make kb-build && make kb-vectorize   # 建知识库并向量化
make mcp-up && make dev   # MCP :8101/:8102 + 应用 :8000
```

浏览器打开 <http://localhost:8000>。没有 `make` 的环境直接运行 Makefile 里对应的一行命令即可。

## 代码结构

| 位置 | 装的是什么 |
| - | - |
| `app/api/` | HTTP 入口。聊天(SSE)、Agent、知识库、复核、评估页、成本看板 |
| `app/graph/` | LangGraph 图。state / nodes / routing / build |
| `app/core/` | 单点能力。上游客户端、检索、重排、意图、指代、摘要、置信度、语义缓存、飞轮、可观测 |
| `app/kb/` | 知识入库。切块、嵌入、双写 MySQL 与 Milvus、去重、对话挖问答对 |
| `app/tools/` | 工具系统。内置 @tool、MCP 客户端、注册表、统一执行引擎 |
| `app/static/` | 前端页面(聊天 / 知识库 / 评估 / 观测 / 主题分布 / 验收) |
| `mcp_servers/` | 两台业务 MCP Server(物流 / 售后),独立进程 |
| `sql/` | 建表与迁移,容器首启按文件名顺序自动执行 |
| `scripts/` | 建库、评估、微调等离线脚本 |

## 测试与质量

- `uv run pytest -q` —— 全部单测(不打真实模型);带 MySQL 的用例需先 `docker compose up -d`。
- GitHub Actions 每次推送跑无外部依赖的单测(graph/core 子集)。
- 二开改动均附单测:语义缓存(命中/阈值/TTL/淘汰/降级)、价保子流程(路由/确认/拒绝/错配守卫)、多上游适配(形状/分片)。
